Sobre este projeto

Este site foi desenvolvido por Luan Henrique como projeto academico da disciplina de Desenvolvimento Front-end para Web (Prof. Israel Cunha), reunindo o conteudo de HTML basico e HTML avancado estudado em sala. O tema escolhido foi o jogo VALORANT, da Riot Games.

O projeto foi construido 100% em HTML5, sem uso de CSS ou JavaScript, conforme exigido pela atividade.

Requisitos do projeto atendidos

  • Tags semanticas (header, nav, main, section, article, aside, footer) em todas as paginas;
  • Elemento audio com controles (pagina Trilha Sonora);
  • Elemento video local com controles (paginas Gameplay, Jett e Videos);
  • Imagem com figure e figcaption (paginas Inicio, Historia, Jett e Mapas);
  • Formulario com date, file, color e range (pagina Cadastro);
  • Campos com required e placeholder (pagina Cadastro);
  • Datalist com sugestoes de agentes (pagina Cadastro);
  • Details e summary (paginas Modos de Jogo e Curiosidades);
  • Marcacao avancada: mark, del, ins, abbr, blockquote, progress e meter (varias paginas);
  • Mais de 10 paginas .html, com navegacao fluida entre todas elas;
  • Projeto organizado em pastas: html/, img/, audio/, video/.

Aviso legal

VALORANT e todos os nomes de agentes, mapas, armas e demais elementos relacionados ao jogo sao marcas registradas da Riot Games, Inc. Este e um projeto academico, sem fins lucrativos, feito exclusivamente para fins educacionais.
