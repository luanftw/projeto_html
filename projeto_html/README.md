Requisitos do projeto atendidos
Tags semânticas (header, nav, main, section, article, aside, footer) em todas as páginas;
<audio> com controles (página Trilha Sonora);
<video> local com controles (páginas Gameplay, Jett e Vídeos);
Imagem com <figure> + <figcaption> (páginas Início, História, Jett e Mapas);
Formulário com date, file, color e range (página Cadastro);
Campos com required e placeholder (página Cadastro);
<datalist> com sugestões de agentes (página Cadastro);
<details> + <summary> (páginas Modos de Jogo e Curiosidades);
Marcação avançada de texto: mark, del, ins, abbr, blockquote, progress e meter (usadas em várias páginas, mais que as 3 mínimas exigidas);
Reaproveitamento de tudo estudado antes: meta tags padrão (author, keywords, description, charset, language), listas ordenadas/não ordenadas, tags isoladas (hr, br, b, i), links, imagens, tabelas (com thead/tbody/tfoot e colspan), formulários (text, email, password, select, radio, checkbox, textarea) e as tags label, fieldset e legend;
Mais de 10 páginas .html, com navegação fluida entre todas elas;
Projeto organizado em pastas: html/, img/, video/;
Sem CSS e sem JavaScript — foco 100% em HTML.
Aviso legal

VALORANT e todos os nomes de agentes, mapas, armas e demais elementos relacionados ao jogo são marcas registradas da Riot Games, Inc. Este é um projeto acadêmico, sem fins lucrativos, feito exclusivamente para fins educacionais.
